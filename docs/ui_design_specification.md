# Facet  - UI 设计说明书

本文档提炼了 Facet 侧栏方案 B 的视觉语言、布局规范和组件交互逻辑。本说明书独立于代码实现，可作为向任何技术栈（如 React, Vue, Flutter, 客户端原生）迁移的设计基准。

---

## 1. 设计系统基础 (Design Tokens)

### 1.1 颜色系统 (Color System)
配色是同一套语义色板的六种取值：一套浅色加五套深色，全部以 CSS 变量定义在 `packages/ui/src/styles/theme.css`，组件只读变量。缺省为深色的 `zinc`，`跟随系统` 在系统偏浅时用 `light`，否则用 `zinc`。

| 配色 | 取向 | 代表色 |
|---|---|---|
| `light` | 浅色 | `#ffffff` |
| `zinc` | 深色（缺省），中性灰 | `#808080` |
| `midnight` | 深色，蓝调 | `#4a6ba8` |
| `claude` | 深色，暖棕 | `#d97757` |
| `ghostty` | 深色，石板蓝 | `#8caaee` |
| `pureBlack` | 深色，纯黑底 | `#000000` |

每套配色都填满同一组变量，取值含义如下。表里的参考值是 `zinc` 与 `light` 两套。

*   **表面背景色 (Surfaces)**：用于构建层级关系。
    *   `--bg`：最底层背景（主视口区）。zinc `#18181b` / light `#ffffff`
    *   `--sb`：侧边栏。zinc `#131316` / light `#f4f4f5`
    *   `--card` / `--card2`：一级面板与其中的卡片。zinc `#1f1f22` / `#27272a`，light `#fafafa` / `#f4f4f5`
    *   `--surface2` / `--surface3` / `--surface4`：悬浮、选中与按下三档。选中的会话行用 `--surface4`
*   **文本颜色 (Text)**：
    *   `--t1`：主文本（标题、正文）。zinc `#fafafa` / light `#1a1a1e`
    *   `--t2`：次文本（描述、次要信息）。zinc `#a1a1aa` / light `#71717a`
    *   `--t3`：弱文本（占位符、辅助时间/数据）。zinc `#71717a` / light `#a1a1aa`
*   **边框与分割线 (Lines)**：
    *   `--line`：常规分割线、边框。zinc `#27272a` / light `#e4e4e7`
    *   `--line2`：强调边框（输入框默认边框）。zinc `#303036` / light `#ececf1`
*   **语义色 (Semantic)**：
    *   `--acc`：强调色的文字版（链接、聚焦描边、指示条）。zinc `#fafafa` / light `#239956`
    *   `--acc-fill`：强调色的填充版（主按钮底色），配 `--on-acc` 的文字。zinc `#e4e4e7` / light `#20744a`
    *   `--ok` / `--warn` / `--err`：成功、警告、失败。状态文字与图标用它，底纹用同色的 `--okbg` / `--warnbg` / `--errbg`
    *   `--dot-ok` / `--dot-warn` / `--dot-err` / `--dot-run`：列表行上的状态点。点只有 6pt，彩度比状态色更高一档
*   **Diff 差异色 (Code Diff)**：
    *   `--add` / `--del`：差异文本色。zinc `#4ade80` / `#ef4444`，light `#15803d` / `#b91c1c`
    *   `--addbg` / `--delbg`：差异行的底色，取同色 16% 透明度
*   **代码配色 (Code Highlight)**：代码块与差异视图的语法高亮另有一套配色，可选 GitHub、Catppuccin、Dracula、Tokyo Night、One、Nord、Gruvbox、Solarized，浅深跟随界面主题。

### 1.1.1 图标 (Icons)
界面图标与 lucide 一致：`lucide-react` 的 24 栅格线性图标，`size` 12 至 16，笔画 `1.5`，颜色跟随文字变量（`currentColor`）。只导入用到的图标，未用的不进入产物。侧栏页脚的设置入口即 `Settings`。

### 1.2 排版规范 (Typography)
*   **无衬线字体 (Sans-serif)**：`Inter` 与 `Noto Sans SC Variable`（都随构建打包）, 系统默认字体。Latin 与数字用 Inter，汉字与中文标点用 Noto Sans SC Variable。用于常规界面文本。
*   **等宽字体 (Monospace)**：`Maple Mono` 与 `Maple Mono CN`（都随构建打包）, 等宽字体。用于代码、文件路径、时间、统计数字。必须启用 `tabular-nums`（等宽数字特性）以保证数字宽度一致。
*   **基础字号 (Base Size)**：界面控件 `13px`；对话正文与用户气泡 `15px`（设置里的「界面字号」，缺省 `15`）。
*   **行高 (Line Height)**：基础行高 `1.55`；对话正文与气泡 `1.4`；标题 `1.3`。
*   **对话排版**：正文与气泡同字号同行高；段落之间 `16px`（与 paseo 的 block gap 一致）；行内代码 `0.8em`、`--surface2` 底、圆角 `4px`、无边框；标题按 `1.6 / 1.4 / 1.2 / 1.1` 放大；气泡 `--surface3` 底、内边距 `16px`、圆角 `16px`，右上角收成 `4px`。

### 1.3 尺寸与圆角 (Sizing & Shape)
*   **全局圆角**：小组件（按钮、标签）`6px`，中等组件（弹窗、代码块）`8px`，大组件（输入框）`12px`。
*   **标准行高 (Row Height)**：列表项（工具条、菜单项）标准高度为 `28px`。

### 1.4 交互与动效 (Interaction & Motion)
*   **焦点状态 (Focus Visible)**：所有可交互元素在键盘聚焦时，必须显示 `2px` 的 `Accent` 颜色外发光（Outline），且偏移 `2px`。
*   **动画缓动曲线 (Easing)**：`cubic-bezier(0.2, 0.6, 0.3, 1)`。
*   **动画时长**：颜色/背景色过渡等极快交互 `120ms`；展开/折叠、旋转等位移变化 `180ms`。
*   **阴影 (Shadow)**：弹窗组件使用统一的 Popover 阴影（向下的大范围柔和阴影）。

## 2. 全局布局结构 (Global Layout)

应用采用三栏式网格布局，高度撑满屏幕，内部区域独立滚动。

*   **左侧边栏 (Sidebar)**：固定宽度 `272px`。背景 `Surface 1`。右侧有 `1px Line` 分割。
*   **中栏主工作区 (Main)**：宽度自适应 (`1fr`)。背景 `Surface 0`。
    *   内部内容区（对话和输入框）约束最大宽度 `720px` 居中显示。
*   **右侧面板 (Right Panel)**：固定宽度 `264px`。背景 `Surface 1`。左侧有 `1px Line` 分割。
*   **消息动作 (Message Actions)**：用户消息底部靠右是 `22×22` 的复制与回退，每轮收尾处靠右是复制与分叉，复制都排在左边。按钮无边框、无底色；用户消息上的两个默认隐藏，悬停该行才出现，收尾处的复制与分叉默认可见。只有指针落在按钮本身时该按钮才转强调色，悬停整行不影响。复制成功后图标换成对勾并保持 1.2 秒。
*   **应用外壳 (App Frame)**：去掉系统标题栏。顶部 `--chrome-height`（`36px`）是一条真正的布局行，按下面的三栏切成三格，格子宽度与正文列共用 `--sidebar-width`、`--panel-width` 两个变量，所以顶带里的东西永远和下面的列对齐：
    *   左格：侧栏头部（应用名、搜索会话、添加项目、收起侧栏）；侧栏展开时这一格带侧栏底色与右缘那条分界线，让正文的分隔一直通到窗口顶边；侧栏收起时这一格宽度收到 `0`，头部整个不渲染
    *   中格：左栏开关（`PanelLeft`），只在侧栏收起、或窄屏抽屉未展开时出现，贴在主区左上角
    *   右格：右栏开关（`PanelRight`）、右栏「文件 / 变更」分页、窗口按钮，宽度等于右栏宽度，展开时左缘带一条分界线接上正文的分隔（分隔条悬停时这条线与正文那段一起变色）；右栏收起时这格收到只剩开关与窗口按钮
    *   整条带铺一层 `app-region: drag`，格子里的控件自己标 `no-drag`；双击空白处由 Chromium 处理成最大化切换
    *   窄屏（`880px` 以下）左格宽度为 `0`，侧栏头部改由抽屉自己画
*   **对话导航 (Chat Outline)**：正文左侧的竖轨，距主区左缘 `--outline-inset`（`8px`，固定值，不随缩放变），宽 `--outline-rail-width`（`36px`），纵向占主区域高度的 10% 到 90%；每条用户消息一根短条，静止 `10×2px`，当前轮次加宽到静止宽度的黄金比例（`16.2px`），指针附近按距离放大到 `22×4px`（半径为 3 条，升余弦衰减，过渡 140ms），加宽与放大叠加时总宽收到轨内宽（`30px`）不溢出；短条的尺寸系列都在 `:root` 里（`--outline-pill-*`），组件只写 `--outline-grow`。整套尺寸按 `--outline-scale` 缩放，倍数来自设置里「对话导航缩放」的百分比（50–200，步长 5，缺省 100）；最小可用宽度按间距加放大后的轨宽现算（`780 + 2 × (8 + 36 × 倍数)`），保证放大后仍然不压正文。悬浮时在竖轨右侧 `2px` 处显示 260px 宽的预览卡，两行截断；条数少于 2 或主区域窄于 868px（100% 缩放时留白放不下间距加轨宽，其余倍数据此现算）时不显示。
*   **右侧栏 (Right Panel)**：宽 `320px`（`260–480` 可拖），左缘 `1px` 分割线外加 `--divider-hit-width`（`6px`）拖拽热区，悬停时把这条分割线染成 `--divider-highlight`；分页在顶带右侧那一格里（选中给 `--surface2` 底），正文从顶带下面开始，独立滚动，内边距 8px。
*   **变更页 (Changes)**：分支头一行（分支名 + `↑N ↓M` + 刷新），下面是文件清单：状态字母（A/M/D/R/?/!）、文件名、所在目录、`+N −M`，二进制显示「二进制」；点一行就地展开 unified diff，一次只展开一个，长行横向滚动不折行；底部一行合计文件数与增删。
*   **文件页 (Files)**：惰性目录树，行高 24px、按层级缩进 12px，目录在前；行内是箭头、图标、名称，加载中给省略号，失败给「读取失败」。打开文件后切到查看态：顶部一行返回按钮与相对路径，下面是 CodeMirror 6 的只读视图（行号、折叠槽、当前行、换行）。
*   **编辑态 (Editing)**：查看态标题栏右侧是铅笔；进入编辑后换成「保存」与退出，未保存时路径后面有一个强调色小圆点。保存成功短暂显示对勾；冲突时在编辑器上方给一行「文件已在磁盘上改动」加「重新加载 / 覆盖」。
*   **设置窗 (Settings)**：浮在应用上的一层，尺寸 `min(920px, 100%)` × `min(660px, 100%)`，居中，圆角 `16px`，底色 `--card`，左侧分类栏 `148px` 用 `--bg`，右侧内容独立滚动；点遮罩或按 Esc 关闭，焦点回到打开它的按钮。分类四页：模型、外观、输入、关于。页内按主题分组：组标题在上，下面是一张卡片，卡片里一行一个设置（左名字、右控件）。外观页「通用」组里依次是主题色板、运行中的动效（呼吸 / 扫光）、减少动效、对话导航缩放（50–200 的百分比，步长 5）。设置没有保存按钮，改动停下 1 秒自动提交，关闭时立刻提交。
*   **模型页 (Models)**：一组「默认设置」（默认模型、默认思考档位），下面是「已配置的提供方」——只列有凭证的与自定义的，行内是名称、凭证状态与凭证/地址/编辑/删除；列表下方一整条虚线按钮「添加提供商」，点开是 `520px` 宽的挑选弹窗：顶部搜索框自动聚焦，全部提供方可按名字过滤，已配置的标「已添加」且不给添加按钮，未配置的点「添加」在行内展开 API key 输入，自定义的排在最后并带「自定义」标记与「编辑」，底部是「添加自定义提供方」与「完成」。最后一组「可用模型」只列已配置提供方的模型，每行一个「测试」。各组只留标题，设置项只留名字与控件，不写说明文字。
*   **响应式规则**：
    *   **宽屏 (`>= 1100px`)**：三栏同时平铺显示。
    *   **窄屏 (`< 1100px`)**：右侧面板默认隐藏。通过主区的“显示文件导航”按钮唤出时，右侧面板以绝对定位抽屉的形式从右侧滑出浮于主视口上方，并附带弹窗阴影。

## 3. 核心模块与组件规范 (Core Modules)

### 3.1 左侧边栏 (Sidebar - 会话与项目管理)
*   **宽度**：缺省 `272px`，右缘一条 `--divider-hit-width`（`6px`）命中区可拖，范围 `220–420`；拖动期间直接改 `--sidebar-width`，松手才提交，宽度与顶带左格同步（与右栏同一套逻辑）。默认值与上下限在 `sidebar-state.ts`，跟着本地存储走，不进主机设置。命中区悬停或拖动时，侧栏自己那条右边线染成 `--divider-highlight`，不加粗也不另叠线；与右栏同一条口径，两边看上去一致。
*   **顶部工具栏 (Header)**：应用标题 `Facet` 在左，搜索会话、添加项目、收起侧栏三个图标按钮靠右对齐（距侧栏右缘 `10px`）；这一行落在窗口顶部那条带里，参与拖动。窄屏抽屉自带一份同样的头部。搜索按钮只负责打开浮窗，输入框不在侧栏里。
*   **核心操作区**：
    *   **新建会话按钮**：占满宽度的强调块。
    *   **项目过滤器 (Project Filter)**：点击弹出下拉列表组件，可全局搜索项目。带有当前项目标签和相关的主机/上下文信息展示。
*   **会话队列列表 (Queue)**：
    *   **分组**：按时间线分组（"进行中", "今天", "昨天", "更早"）。组标题展示组名及数量。
    *   **列表项 (Row)**：Hover 时背景变 `Surface 2`。Active（当前选中）时背景变 `Surface 3`，且左侧增加 `2px` 宽度的 `Accent` 指示条。
    *   **状态点 (Dot)**：位于列表项左侧。
        *   绿色实心：完成/成功。
        *   黄色实心：警告/待应答/执行中。
        *   紫色实心：新消息/未读。
        *   空心圆环：离线/未激活。
*   **搜索浮窗 (Session Search)**：`⌘K` 或头部搜索按钮打开的一层浮窗，居中偏上（距正文上沿 `12vh`），宽 `min(560px, 100vw - 32px)`，圆角 `12px`，底色 `--card`，1px 描边加一层大阴影；遮罩盖住正文与两条侧栏，让出窗口顶部那条带，点遮罩关闭。顶部是图标加输入框（自动聚焦、`15px`），下面按改动时间倒序列出匹配的会话，每条是状态点、标题、项目名与相对时间，当前会话的时间用 `--acc`；上下键走、回车打开、Esc 关闭，最多 40 条，无匹配时给一行「没有匹配的会话」。侧栏里的队列不参与过滤，浮窗关掉之后还是完整的一份列表。
*   **底部区域**：
    *   **页脚 (Footer)**：左起主机切换与主题切换两个图标按钮，右端是设置；不再显示主机名；主机切换点开是主机清单，列出本机与已添加的远程主机，行内是状态点、名字与 `host:port`，底部「添加主机」。关闭窗口后主机一律留在后台，这里不再给开关与结束主机的入口。

### 3.2 主工作区 (Main - 聊天与编辑器)
*   **顶部导航 (Workspace Header)**：
    *   选项卡容器（对话、打开的文件）。支持横向滚动，隐藏滚动条。
    *   全局滚动条：细的悬浮条，没有外框、轨道与两端的箭头，只剩一条 40% 不透明的拇指，指针落上去提亮；需要完全隐藏的地方用 `::-webkit-scrollbar { display: none }` 覆盖。Chromium 给了 `scrollbar-width`/`scrollbar-color` 会改按标准画并带箭头，所以这边只走 webkit 伪元素。
    *   当前文件激活时，右侧显示编辑器工具（查看模式切换：预览/内容/改动）。
*   **对话流 (Timeline)**：焦点管理 (Accessibility/Focus)：所有按钮、输入框、树状菜单项必须支持 Tab 键获取焦点。弹出项目切换器时，焦点需限制在弹窗内（Focus Trap），关闭时焦点需恢复到原按钮。
    *   向下滚动，顶部包含会话标题和 Meta 信息。
    *   **用户气泡 (User)**：包含提示符（`>`）和文字。
    *   **过程行 (Process)**：一次提问里没有正文的那些消息合成一行。收起时是一行：扳手图标 + 标题，标题按这一组做了什么事归类计数，例如「运行了 5 个命令」「编辑了 2 个文件和运行了 3 个命令」；只有思考时是「已思考」。默认收起，收起时没有底色，悬停只让文字由 `--t2` 变到 `--t1`。展开后标题才带 `--surface2` 药丸底、左侧换成朝下的箭头，下面是左侧 `1px` 竖线的缩进区：竖线落在箭头字形的左缘，行内容距竖线由 `--indent-rail-offset` 给出（缺省 `16px`），竖线相对正文列的位置由 `--indent-rail-inset` 给出（缺省 `4px`，来自箭头字形在图标盒子里的内缩）；行首图标边长 `--indent-rail-icon`（缺省 `14px`）、图标到短名的间距 `--indent-rail-gap`（缺省 `8px`），短名列与输出、思考正文的缩进都由这两项相加得到。
    *   **缩进区 (Group Body)**：一行一个动作，行首是 14px 图标（命令、读取、编辑、搜索、其他），接着是短名（Shell、Read、Edit、Grep 等），再往后是等宽字体的参数摘要，单行省略。点这一行才展开输出，输出没有边框与底色，直接缩进在下面；超过 12 行或 1400 字先折起来给「显示全部」。行悬停不加底色：短名默认 `--t2`，悬停或这一行已展开时变 `--t1`。成败只由短名的颜色区分：失败 `--err`，被中止而没执行到 `--warn`；正在执行的这一行由短名与参数摘要上的扫光表示，行尾不加任何标记，也不写状态文字。
    *   **思考行 (Thinking)**：同一组里的一行，大脑图标 + `Thinking`，点开是正文，正文用界面字体。这一轮没有工具调用时它直接落在答复正文里，与 Markdown 左对齐，收起态的悬停与过程组一致（只变文字颜色，没有底色）。
    *   **流式状态**：回合还在跑时，组标题与正在执行的工具行用同一套动效表示在跑，落在文字上，不再另加状态点。缺省是呼吸：文字保持 `--t1`，`opacity` 在 0.45 与 1 之间按 1.6s 循环（只改不透明度，由合成器执行，文字不参与重绘）。设置里把「运行中的动效」改成「扫光」后换成 `background-clip: text` 的渐变带扫过（`--t2` 打底、`--t1` 作亮带，1.9s 循环），观感更明显，但逐帧重绘文字。两种都随回合结束即停；`prefers-reduced-motion: reduce` 下都不播动画，文字停在 `--t1`。
    *   **富文本 (Prose)**：支持 Markdown 渲染和行内代码块。
    *   **代码块 (Code)**：带有语言标签和“复制”功能（Hover唤出），支持语法高亮。
    *   **变更总结 (Changes)**：展示文件修改的统计（新增行数、删除行数）。
    *   **收尾行 (Turn Footer)**：这一轮结束时一行，左起复制、分叉，右边写这一轮的工作时长，格式与 paseo 一致：`工作了 7s`、`工作了 3m 16s`、`工作了 1h 5m`；还在跑时由界面自己计时。
*   **错误提示 (Error)**：一层 `--errbg` 浅底、圆角 6px、内边距 12px 10px，不描边；左上是 16px 的圆形警示图标，固定在列首不参与收缩，不写「出错」二字。正文用 `--t1` 与正文字号，`overflow-wrap: anywhere` 让长串报错（JSON、请求标识）在任意位置断开。动作是「重试」与「复制详情」两个文字按钮，排在正文下方，悬停转 `--t1` 并加下划线。
*   **输入框区域 (Composer)**：
    *   固定在页面底部。
    *   **引用区域 (File Reference)**：如在代码中选择了某几行，会在输入框上方显示引用的文件和行号标签。
    *   **输入框 (Textarea)**：外边框为 `Line Strong`。聚焦时边框变为 `Accent`，并增加发光阴影环。
    *   **操作栏**：左侧是「+」添加菜单与两个芯片——模型芯片显示模型名，思考芯片显示大脑图标加档位取值（Off 到 Max，不翻译）；两个芯片默认没有底色，悬停或展开时才有 `--surface2` 底与下拉箭头（收起朝下、展开朝上）。右侧是上下文用量环与一个 34×34 的主按钮：有内容要发时是发送箭头（运行中即排队），这一轮在跑而没有内容可发时换成停止——同一个方框、同样的 10px 圆角，中间换成红色方块，两种形态互相替换，位置不动。

### 3.3 编辑器视图 (File View)
如果激活了文件选项卡，主区的内容替换为代码编辑器。
*   **行号区**：固定在左侧，等宽数字，文本颜色较弱。
*   **源代码区**：横向防溢出。支持 `token` 级别的语法高亮（Keyword, String, Number 等）。
*   **Diff 模式**：差异行整行背景色变更（绿底/红底），并在行号旁用 `+` 或 `−` 标识。
*   **底部信息栏**：绝对路径面包屑，所属节点，语言，编码，以及只读状态。

### 3.4 右侧面板 (Panel - 工作区文件)
*   **顶部 Tabs**：在“文件 (Files)” 和 “改动 (Changes)” 之间切换。带徽标数字提示。
*   **项目信息**：当前项目名与所属主机。
*   **文件树 (File Tree)**：
    *   带有即时过滤的搜索输入框。
    *   层级缩进公式：`padding-left = 4px + (深度 * 12px)`。
    *   文件夹前带三角 Chevron 图标（展开时旋转 90 度）。
    *   被修改过的文件右侧带黄色的“已修改”标签。
    *   支持键盘上下箭头导航，Enter/Space 展开或打开文件。
*   **改动列表 (Changes List)**：
    *   平铺展示被修改的文件。
    *   显示独立的新增 (`+42`) 和删除 (`-18`) 的等宽数字统计。

## 4. 关键交互状态要求 (Interaction Guidelines)

设计实现时必须保证以下交互逻辑的完整性：

1.  **组件溢出 (Overflow)**：文件路径、项目名称等长文本必须处理文本截断，统一使用单行省略号 (`text-overflow: ellipsis`)。
2.  **状态互斥 (State Toggling)**：
    *   主题切换会改写根节点的 `data-theme`，配色按此选择变量组；代码配色同时随深浅切换版本。
    *   右面板的隐藏与显示会改变整体 Grid 的列数分配或触发弹窗定位。
    *   对话输入时的“引用文件”，可通过在代码编辑器中点击行号（支持 Shift 多选）触发引用标签生成。
3.  **浮出层定位 (Popover Positioning)**：项目选择下拉菜单需自动计算上下可用空间。如果底部空间不足且顶部空间充足，菜单应当向上弹出（底对齐），防止遮挡视口。
