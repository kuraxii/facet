# 功能需求

本文件列出 facet 的功能需求，作为设计与实现的功能基线。每条需求有稳定编号，后续详细设计按编号逐条展开。

## 阅读方式

- 编号：`FR-<域>-<序号>`。域划分见目录。
- 优先级：**P0** 核心，没有它应用不可用；**P1** 重要，缺失会让产品失去竞争力；**P2** 增强，可在核心稳定后补。
- 复杂度：按实现工作量估计的粗档（小 / 中 / 大），用于排期参考，不作为取舍依据。
- 取舍列记结论：保留 / 简化 / 移除；空表示未定。
- 界面视觉与组件规格以 `docs/ui_design_specification.md` 为基线，侧栏按其中的方案 B 组织。

| 域 | 前缀 | 范围 |
|---|---|---|
| 应用外壳 | SHELL | 窗口、退出确认 |
| 项目与导航 | NAV | 项目、顶栏、空状态 |
| 侧栏 | SIDE | 分区、新会话、搜索、项目过滤器与时间分组队列、会话行、页脚 |
| 会话生命周期 | SESS | 新建、打开、分叉、撤回、删除、卸载 |
| 对话渲染 | CHAT | 消息流、markdown、工具卡、图片、错误 |
| 输入与发送 | COMPOSE | 输入框、补全、排队、附件 |
| 权限与信任 | PERM | 项目信任、路径边界；工具审批与规则由 pi 扩展提供 |
| 扩展与工具 | EXT | 扩展 UI、内置工具、MCP、社区包 |
| 文件与差异 | FILES | 文件树、编辑器、差异侧栏 |
| 终端 | TERM | 伪终端、分屏、终端设置 |
| 设置 | SET | 提供方、模型、外观、各面板 |
| UI 插件 | PLUG | 槽位、宿主接口、构建 |
| 跨主机访问 | XDEV | 多主机接入与多端同步、远程权限与审计 |
| 数据与持久化 | DATA | 写入磁盘、事件顺序、状态重放 |
| 非功能 | NFR | 性能、可靠性、安全、可测 |

# 三、侧栏（SIDE）

侧栏按设计稿方案 B 组织，自上而下为顶部标题栏、新建会话、项目过滤器、会话队列、页脚。项目维度由过滤器承担，队列不按项目分组，按时间分组。宽度与折叠归本域，会话本身的动作归 SESS。

| 编号 | 需求 | 行为要点 | 优先级 | 复杂度 | 取舍 |
|---|---|---|---|---|---|
| FR-SIDE-01 | 侧栏分区 | 自上而下为顶部标题栏（应用名、搜索会话、添加项目、收起侧栏）、新建会话、项目过滤器、会话队列、页脚（主机、主题与设置，右端是设置）；顺序固定，不提供自定义排序。右缘可拖宽，缺省 272px，范围 220–420，宽度记在本机 | P0 | 中 | 已实现 |
| FR-SIDE-02 | 新会话 | 占满宽度的强调色块；工作目录取过滤器当前项目的目录，过滤器为全部项目时取上次使用的项目；无可用项目时置灰并引导添加 | P0 | 小 | 保留 |
| FR-SIDE-03 | 搜索 | 标题栏搜索图标或 ⌘K 打开居中的搜索浮窗：输入即按标题过滤全部会话，上下键选、回车打开、Esc 关闭；队列本身不过滤，无匹配时给一行说明；项目搜索在项目过滤器内单独提供 | P1 | 中 | 已实现（只按标题，不搜消息内容） |
| FR-SIDE-04 | 日常 | 侧栏顶部区域内的固定入口，进入固定的草稿工作目录，随手提问用；会话侧规则见 FR-SESS-13，这里只规定入口位置与呈现 | P2 | 中 | |
| FR-SIDE-05 | 最近会话 | 跨项目固定 8 条、顺序持久化、可收起；只在发消息或停留满 10 秒时记录，仅浏览不记录；日常与只读检视会话不计入 | P1 | 中 | 移除（由时间分组队列代替） |
| FR-SIDE-06 | 项目过滤器与队列 | 过滤器展示当前范围名与会话数，下拉可搜索、切到全部项目、添加项目；选项含用户添加的项目与会话里出现的目录，按会话数倒序；队列按进行中、今天、昨天、更早分组，组标题带数量，组内按修改时间倒序；全部项目时行内显示所属目录名 | P0 | 中 | 保留 |
| FR-SIDE-07 | 主机状态条 | 横向排列本机与远程主机，标明连接状态与会话数 | P1 | 中 | 移除（并入页脚的主机切换） |
| FR-SIDE-08 | 会话行 | 标题、时间、状态点；行高 28px，悬浮为表面二级色，当前会话为表面三级色并在左侧加 2px 强调色指示条；状态点当前只有运行中与空闲两态，完成与未读需要主机侧提供未读与待应答信息 | P0 | 中 | 简化（状态点两态） |
| FR-SIDE-09 | 会话行菜单 | 重命名、删除、导出、复制路径、打开所在目录；删除需确认 | P1 | 小 | 简化（先做改名与删除，路径动作随 FR-FILES-06） |

# 四、会话生命周期（SESS）

| 编号 | 需求 | 行为要点 | 优先级 | 复杂度 | 取舍 |
|---|---|---|---|---|---|
| FR-SESS-01 | 新建会话 | 指定工作目录、模型、思考档位；缺省用全局默认 | P0 | 中 | |
| FR-SESS-02 | 打开历史会话 | 读会话文件回放完整分支历史；打开期间到达的实时事件要等历史就绪后合流，不能乱序 | P0 | 大 | |
| FR-SESS-03 | 会话回收 | 按打开会话的端计数，计数归零后延迟回收；有动作在途、运行中或压缩时不回收，等这一段结束后再计 | P0 | 中 | |
| FR-SESS-04 | 删除会话 | 同时删除磁盘会话文件；不可恢复；操作前确认 | P0 | 小 | |
| FR-SESS-05 | 会话改名 | 活跃会话直接改；历史会话离线追加一条会话信息记录，不启动会话 | P1 | 中 | |
| FR-SESS-06 | 分叉会话 | 在任意一轮结束时分叉出新会话，保留到该轮结束为止的全部内容；最后一轮的分叉取当前对话末尾。分叉点取下一轮开始处的前一条，压缩、改名等尾随条目一并保留 | P1 | 大 | |
| FR-SESS-07 | 撤回消息 | 撤回自己发出的消息：分支指针挪到这条消息之前，原文放回输入框，会话文件保持只追加，被放弃的一段成为另一条分支；跑动中不允许撤回；第一条用户消息之前没有可回退的轮次 | P1 | 大 | |
| FR-SESS-08 | 重试失败轮次 | 只重试末端失败的模型调用，不新增用户消息；结果走事件流 | P1 | 中 | |
| FR-SESS-09 | 导出会话 | 导出 HTML 与 JSONL | P2 | 中 | 移除 |
| FR-SESS-10 | 会话自动卸载 | 长时间离开的会话释放其运行态，释放内存；受频道订阅与运行状态保护；装载的会话超过数量上限时按最久未用回收，界面正开着的与在跑的不动；卸载不影响侧栏行的存在 | P1 | 大 | 保留 |
| FR-SESS-11 | 只读子代理检视 | 点击子代理运行卡打开其子会话，只读展示，可返回父会话；子会话不出现在导航里 | P1 | 中 | 放弃（不做子代理） |
| FR-SESS-12 | 会话状态机 | 空闲 / 运行中 / 压缩中；状态同时驱动侧栏状态点与输入框可用性 | P0 | 中 | |
| FR-SESS-13 | 日常空间 | 固定草稿工作目录，随手提问用；与项目会话在项目过滤与时间分组上区别对待 | P2 | 中 | |

# 附录 A：取舍候选

以下功能在维护成本上占比明显，需要在详细设计前给出保留或移除的结论。

| 候选 | 影响范围 | 保留的收益 | 移除或简化的代价 |
|---|---|---|---|
| UI 插件体系 | FR-PLUG-01 至 07，宿主接口、构建链路、内置与示例插件 | 插件可替换界面槽位、在固定区域挂载内容，界面扩展不必改主程序 | 放弃整块界面扩展能力；若只保留区域挂载可保留少量装饰能力 |
| 跨主机访问 | FR-XDEV-01 至 19，连接认证、权限档与审计 | 手机与另一台电脑能同时查看并操作主机上的工作，端只是入口 | 放弃多端接入，端与主机合并，会话只能在本机操作；并发冲突靠主机侧按会话串行执行写入解决，不需要项目独占 |
| 内建终端 | FR-TERM-01 至 05，伪终端与原生模块 | 不切窗口即可执行命令 | 需要用户自备终端；原生模块的跨平台编译问题一并消失 |

# 附录 B：待讨论清单

详细设计阶段需要逐条定的问题，按优先级排列。

1. **性能路线**（FR-NFR-01、FR-NFR-02）：行模型是否做增量缓存；流式事件合并的粒度。
2. **事件管道**（FR-DATA-05、FR-DATA-06）：事件序号与补齐策略；是否需要按会话独立的传输端口（高频输出场景）。
3. **扩展能力边界**（FR-EXT-01 至 04）：图形界面支持到哪一步；无法承载的能力如何明确失败。
4. **权限模型**（FR-PERM-01 至 10）：审批与规则已移出应用，由 pi 扩展承担；需要定的是项目信任与路径边界（FR-PERM-04、FR-PERM-09）的实施范围与判定位置。
5. **端与主机之间的接口形态**（全部）：帧格式与二进制通道；请求标识与失效判定的位置；通道表的组织方式；运行时校验放在哪一层；事件与调用的比例。
6. **状态所有权**（FR-DATA-*、FR-SESS-10）：哪份数据是权威、谁负责清理；自动卸载的判定条件。
7. **界面状态结构**（FR-CHAT-*、FR-COMPOSE-03）：会话级与全局状态的边界；草稿与队列的归属。
8. **插件体系取舍**（FR-PLUG-*）：保留几个槽位；宿主接口开放到哪一步；是否只支持内置插件。
9. **文件与差异的深度**（FR-FILES-*）：只读查看与可编辑的界线；差异侧栏的数据来源是工具输出还是真实文件比对。
10. **发行包**（FR-NFR-08）：rpm 与 deb 的依赖与安装位置；原生模块（node-pty）在包内的加载路径。
