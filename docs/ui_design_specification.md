# Facet  - UI 设计说明书

本文档提炼了 Facet 侧栏方案 B 的视觉语言、布局规范和组件交互逻辑。本说明书独立于代码实现，可作为向任何技术栈（如 React, Vue, Flutter, 客户端原生）迁移的设计基准。

---

## 1. 设计系统基础 (Design Tokens)

### 1.1 颜色系统 (Color System)
配色是同一套语义色板的六种取值：一套浅色加五套深色，全部以 CSS 变量定义在 `packages/ui/src/styles/theme.css`，组件只读变量。缺省为深色的 `zinc`，`跟随系统` 在系统偏浅时用 `light`，否则用 `zinc`。

| 配色 | 取向 | 代表色 |
|---|---|---|
| `light` | 浅色 | `#ffffff` |
| `zinc` | 深色（缺省），中性灰 | `#808080` |
| `midnight` | 深色，蓝调 | `#4a6ba8` |
| `claude` | 深色，暖棕 | `#d97757` |
| `ghostty` | 深色，石板蓝 | `#8caaee` |
| `pureBlack` | 深色，纯黑底 | `#000000` |

每套配色都填满同一组变量，取值含义如下。表里的参考值是 `zinc` 与 `light` 两套。

*   **表面背景色 (Surfaces)**：用于构建层级关系。
    *   `--bg`：最底层背景（主视口区）。zinc `#18181b` / light `#ffffff`
    *   `--sb`：侧边栏。zinc `#131316` / light `#f4f4f5`
    *   `--card` / `--card2`：一级面板与其中的卡片。zinc `#1f1f22` / `#27272a`，light `#fafafa` / `#f4f4f5`
    *   `--surface2` / `--surface3` / `--surface4`：悬浮、选中与按下三档。选中的会话行用 `--surface4`
*   **文本颜色 (Text)**：
    *   `--t1`：主文本（标题、正文）。zinc `#fafafa` / light `#1a1a1e`
    *   `--t2`：次文本（描述、次要信息）。zinc `#a1a1aa` / light `#71717a`
    *   `--t3`：弱文本（占位符、辅助时间/数据）。zinc `#71717a` / light `#a1a1aa`
*   **边框与分割线 (Lines)**：
    *   `--line`：常规分割线、边框。zinc `#27272a` / light `#e4e4e7`
    *   `--line2`：强调边框（输入框默认边框）。zinc `#303036` / light `#ececf1`
*   **语义色 (Semantic)**：
    *   `--acc`：强调色的文字版（链接、聚焦描边、指示条）。zinc `#fafafa` / light `#239956`
    *   `--acc-fill`：强调色的填充版（主按钮底色），配 `--on-acc` 的文字。zinc `#e4e4e7` / light `#20744a`
    *   `--ok` / `--warn` / `--err`：成功、警告、失败。状态文字与图标用它，底纹用同色的 `--okbg` / `--warnbg` / `--errbg`
    *   `--dot-ok` / `--dot-warn` / `--dot-err` / `--dot-run`：列表行上的状态点。点只有 6pt，彩度比状态色更高一档
*   **Diff 差异色 (Code Diff)**：
    *   `--add` / `--del`：差异文本色。zinc `#4ade80` / `#ef4444`，light `#15803d` / `#b91c1c`
    *   `--addbg` / `--delbg`：差异行的底色，取同色 16% 透明度
*   **代码配色 (Code Highlight)**：代码块与差异视图的语法高亮另有一套配色，可选 GitHub、Catppuccin、Dracula、Tokyo Night、One、Nord、Gruvbox、Solarized，浅深跟随界面主题。

### 1.1.1 图标 (Icons)
界面图标与 lucide 一致：`lucide-react` 的 24 栅格线性图标，`size` 12 至 16，笔画 `1.5`，颜色跟随文字变量（`currentColor`）。只导入用到的图标，未用的不进入产物。侧栏页脚的设置入口即 `Settings`。

### 1.2 排版规范 (Typography)
*   **无衬线字体 (Sans-serif)**：`Inter` 与 `Noto Sans SC Variable`（都随构建打包）, 系统默认字体。Latin 与数字用 Inter，汉字与中文标点用 Noto Sans SC Variable。用于常规界面文本。
*   **等宽字体 (Monospace)**：`Maple Mono` 与 `Maple Mono CN`（都随构建打包）, 等宽字体。用于代码、文件路径、时间、统计数字。必须启用 `tabular-nums`（等宽数字特性）以保证数字宽度一致。
*   **基础字号 (Base Size)**：全局默认 `13px`。
*   **行高 (Line Height)**：基础行高 `1.55`，对话气泡内采用 `1.7`。

### 1.3 尺寸与圆角 (Sizing & Shape)
*   **全局圆角**：小组件（按钮、标签）`6px`，中等组件（弹窗、代码块）`8px`，大组件（输入框）`12px`。
*   **标准行高 (Row Height)**：列表项（工具条、菜单项）标准高度为 `28px`。

### 1.4 交互与动效 (Interaction & Motion)
*   **焦点状态 (Focus Visible)**：所有可交互元素在键盘聚焦时，必须显示 `2px` 的 `Accent` 颜色外发光（Outline），且偏移 `2px`。
*   **动画缓动曲线 (Easing)**：`cubic-bezier(0.2, 0.6, 0.3, 1)`。
*   **动画时长**：颜色/背景色过渡等极快交互 `120ms`；展开/折叠、旋转等位移变化 `180ms`。
*   **阴影 (Shadow)**：弹窗组件使用统一的 Popover 阴影（向下的大范围柔和阴影）。

## 2. 全局布局结构 (Global Layout)

应用采用三栏式网格布局，高度撑满屏幕，内部区域独立滚动。

*   **左侧边栏 (Sidebar)**：固定宽度 `272px`。背景 `Surface 1`。右侧有 `1px Line` 分割。
*   **中栏主工作区 (Main)**：宽度自适应 (`1fr`)。背景 `Surface 0`。
    *   内部内容区（对话和输入框）约束最大宽度 `720px` 居中显示。
*   **右侧面板 (Right Panel)**：固定宽度 `264px`。背景 `Surface 1`。左侧有 `1px Line` 分割。
*   **消息动作 (Message Actions)**：用户消息底部靠右是 `22×22` 的复制与回退，每轮收尾处靠右是复制与分叉，复制都排在左边。按钮无边框、无底色；用户消息上的两个默认隐藏，悬停该行才出现，收尾处的复制与分叉默认可见。只有指针落在按钮本身时该按钮才转强调色，悬停整行不影响。复制成功后图标换成对勾并保持 1.2 秒。
*   **对话导航 (Chat Outline)**：正文左侧的竖轨，宽 `24px`，纵向占主区域高度的 10% 到 90%；每条用户消息一根短条，静止 `8×2px`、当前轮次 `14×2px`、指针附近按距离放大到 `20×4px`（半径 3 条，升余弦衰减，过渡 140ms）；悬浮时在右侧 `26px` 处显示 260px 宽的预览卡，两行截断；条数少于 2 或主区域窄于 720px 时不显示。
*   **右侧栏 (Right Panel)**：宽 `320px`（`260–480` 可拖），左缘 `1px` 分割线外加 6px 拖拽热区，头部 38px 高，放「文件 / 变更」两个分页与收起按钮；分页选中给 `--surface2` 底，正文区独立滚动，内边距 8px。
*   **变更页 (Changes)**：分支头一行（分支名 + `↑N ↓M` + 刷新），下面是文件清单：状态字母（A/M/D/R/?/!）、文件名、所在目录、`+N −M`，二进制显示「二进制」；点一行就地展开 unified diff，一次只展开一个，长行横向滚动不折行；底部一行合计文件数与增删。
*   **文件页 (Files)**：惰性目录树，行高 24px、按层级缩进 12px，目录在前；行内是箭头、图标、名称，加载中给省略号，失败给「读取失败」。打开文件后切到查看态：顶部一行返回按钮与相对路径，下面是 CodeMirror 6 的只读视图（行号、折叠槽、当前行、换行）。
*   **编辑态 (Editing)**：查看态标题栏右侧是铅笔；进入编辑后换成「保存」与退出，未保存时路径后面有一个强调色小圆点。保存成功短暂显示对勾；冲突时在编辑器上方给一行「文件已在磁盘上改动」加「重新加载 / 覆盖」。
*   **设置窗 (Settings)**：浮在应用上的一层，尺寸 `min(920px, 100%)` × `min(660px, 100%)`，居中，圆角 `16px`，底色 `--card`，左侧分类栏 `148px` 用 `--bg`，右侧内容独立滚动；点遮罩或按 Esc 关闭，焦点回到打开它的按钮。
*   **响应式规则**：
    *   **宽屏 (`>= 1100px`)**：三栏同时平铺显示。
    *   **窄屏 (`< 1100px`)**：右侧面板默认隐藏。通过主区的“显示文件导航”按钮唤出时，右侧面板以绝对定位抽屉的形式从右侧滑出浮于主视口上方，并附带弹窗阴影。

## 3. 核心模块与组件规范 (Core Modules)

### 3.1 左侧边栏 (Sidebar - 会话与项目管理)
*   **顶部工具栏 (Header)**：包含应用标题和全局操作图标。
*   **核心操作区**：
    *   **新建会话按钮**：占满宽度的强调块。
    *   **项目过滤器 (Project Filter)**：点击弹出下拉列表组件，可全局搜索项目。带有当前项目标签和相关的主机/上下文信息展示。
*   **会话队列列表 (Queue)**：
    *   **分组**：按时间线分组（"进行中", "今天", "昨天", "更早"）。组标题展示组名及数量。
    *   **列表项 (Row)**：Hover 时背景变 `Surface 2`。Active（当前选中）时背景变 `Surface 3`，且左侧增加 `2px` 宽度的 `Accent` 指示条。
    *   **状态点 (Dot)**：位于列表项左侧。
        *   绿色实心：完成/成功。
        *   黄色实心：警告/待应答/执行中。
        *   紫色实心：新消息/未读。
        *   空心圆环：离线/未激活。
*   **底部区域**：
    *   **页脚 (Footer)**：主机切换、设置与主题切换三个图标按钮，右侧是当前主机名；主机切换点开是主机清单，列出本机与已添加的远程主机，行内是状态点、名字与 `host:port`，底部「添加主机」。关闭窗口后主机一律留在后台，这里不再给开关与结束主机的入口。

### 3.2 主工作区 (Main - 聊天与编辑器)
*   **顶部导航 (Workspace Header)**：
    *   选项卡容器（对话、打开的文件）。支持横向滚动，隐藏滚动条。
    *   当前文件激活时，右侧显示编辑器工具（查看模式切换：预览/内容/改动）。
*   **对话流 (Timeline)**：焦点管理 (Accessibility/Focus)：所有按钮、输入框、树状菜单项必须支持 Tab 键获取焦点。弹出项目切换器时，焦点需限制在弹窗内（Focus Trap），关闭时焦点需恢复到原按钮。
    *   向下滚动，顶部包含会话标题和 Meta 信息。
    *   **用户气泡 (User)**：包含提示符（`>`）和文字。
    *   **Agent 块 (Block)**：左侧带有 `1px` 分割线缩进。包含折叠的“工作计划”详情、以及具体调用的“工具条 (Tool Row)”。工具条展示名称、参数、耗时及状态。
    *   **富文本 (Prose)**：支持 Markdown 渲染和行内代码块。
    *   **代码块 (Code)**：带有语言标签和“复制”功能（Hover唤出），支持语法高亮。
    *   **变更总结 (Changes)**：展示文件修改的统计（新增行数、删除行数）。
*   **错误提示 (Error)**：左侧使用粗红边框的区块，包含重试动作。
*   **输入框区域 (Composer)**：
    *   固定在页面底部。
    *   **引用区域 (File Reference)**：如在代码中选择了某几行，会在输入框上方显示引用的文件和行号标签。
    *   **输入框 (Textarea)**：外边框为 `Line Strong`。聚焦时边框变为 `Accent`，并增加发光阴影环。
    *   **操作栏**：左侧是「+」添加菜单与两个芯片——模型芯片显示模型名，思考芯片显示大脑图标加档位取值（Off 到 Max，不翻译）；两个芯片默认没有底色，悬停或展开时才有 `--surface2` 底与下拉箭头（收起朝下、展开朝上）。右侧是使用量统计与发送按钮。

### 3.3 编辑器视图 (File View)
如果激活了文件选项卡，主区的内容替换为代码编辑器。
*   **行号区**：固定在左侧，等宽数字，文本颜色较弱。
*   **源代码区**：横向防溢出。支持 `token` 级别的语法高亮（Keyword, String, Number 等）。
*   **Diff 模式**：差异行整行背景色变更（绿底/红底），并在行号旁用 `+` 或 `−` 标识。
*   **底部信息栏**：绝对路径面包屑，所属节点，语言，编码，以及只读状态。

### 3.4 右侧面板 (Panel - 工作区文件)
*   **顶部 Tabs**：在“文件 (Files)” 和 “改动 (Changes)” 之间切换。带徽标数字提示。
*   **项目信息**：当前项目名与所属主机。
*   **文件树 (File Tree)**：
    *   带有即时过滤的搜索输入框。
    *   层级缩进公式：`padding-left = 4px + (深度 * 12px)`。
    *   文件夹前带三角 Chevron 图标（展开时旋转 90 度）。
    *   被修改过的文件右侧带黄色的“已修改”标签。
    *   支持键盘上下箭头导航，Enter/Space 展开或打开文件。
*   **改动列表 (Changes List)**：
    *   平铺展示被修改的文件。
    *   显示独立的新增 (`+42`) 和删除 (`-18`) 的等宽数字统计。

## 4. 关键交互状态要求 (Interaction Guidelines)

设计实现时必须保证以下交互逻辑的完整性：

1.  **组件溢出 (Overflow)**：文件路径、项目名称等长文本必须处理文本截断，统一使用单行省略号 (`text-overflow: ellipsis`)。
2.  **状态互斥 (State Toggling)**：
    *   主题切换会改写根节点的 `data-theme`，配色按此选择变量组；代码配色同时随深浅切换版本。
    *   右面板的隐藏与显示会改变整体 Grid 的列数分配或触发弹窗定位。
    *   对话输入时的“引用文件”，可通过在代码编辑器中点击行号（支持 Shift 多选）触发引用标签生成。
3.  **浮出层定位 (Popover Positioning)**：项目选择下拉菜单需自动计算上下可用空间。如果底部空间不足且顶部空间充足，菜单应当向上弹出（底对齐），防止遮挡视口。
