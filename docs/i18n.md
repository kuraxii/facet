# 界面语言

## 语言

- 源语言是 `en`，`packages/i18n/src/resources.ts` 的 `en` 是新增文案的唯一来源。
- 简体中文是 `zh-CN` 翻译资源。
- 首批只支持 `en` 和 `zh-CN`。

## 选择规则

语言设置存本机，不同步主机。取值是 `auto`、`en`、`zh-CN`，缺省 `auto`。

1. 用户明确选择 `en` 或 `zh-CN` 时直接使用。
2. `auto` 读取系统语言：所有中文区域映射到 `zh-CN`，其它语言映射到 `en`。
3. 无法识别时回退到 `en`。

桌面主进程用 `app.getLocale()` 解析，Web 用 `navigator.language`。桌面把解析后的语言通过启动参数交给渲染进程，保证原生弹窗和页面首帧使用同一种语言。

## 包边界

- `packages/i18n` 只依赖 `i18next`，提供资源、语言解析和 `createI18n()`。
- `packages/ui` 提供 `I18nProvider` 与 `useI18n`，包装 `react-i18next`。
- `apps/desktop` 主进程直接使用 `@facet/i18n`，不导入 React 包。
- `apps/web` 复用 `packages/ui` 的 Provider。

## 文案范围

只翻译界面外壳、按钮、标题、设置项和原生弹窗。模型回复、工具输出、代码内容与用户数据不翻译。

服务端、agent、传输层和桌面主进程的错误消息、调试信息与日志统一使用英文源码。界面直接展示这些文本时保持英文，后续如需本地化，应改为错误码由界面翻译。

## 迁移

界面外壳、侧栏、输入区、对话行、设置页、文件与变更面板、Markdown/Mermaid 工具条、窗口按钮、终端面板和文件编辑器已迁移到 `t()`。

新增或修改文案时先写 `en`，再补 `zh-CN`。测试中的界面断言应显式指定语言，避免跟随运行环境。
